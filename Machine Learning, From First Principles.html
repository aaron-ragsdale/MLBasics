What is a scalar?↗

Start with the simplest kind of data: one number that describes a quantity.

GoalRecognize a scalar as a single value, not a list or a direction.

What is happening?

A scalar represents one magnitude, such as temperature, speed, or a model’s loss. It can have units, but no direction.

Why it matters in ML

Machine learning uses scalars for individual measurements, weights, errors, and learning rates.

In short A scalar is one number. Changing it changes the quantity, not a direction.
